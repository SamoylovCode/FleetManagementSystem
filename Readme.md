# Автоколонна Monitor

## 📌 Описание

Веб-приложение, предназначенное для автоматизации процессов, связанных с управлением транспортными средствами, сотрудниками и документацией в рамках одной или нескольких организаций.  
Система предоставляет гибкие механизмы аутентификации и авторизации, модульную структуру представлений, поддержку работы с модальными окнами и реализацию бизнес-логики через сервисы.

Приложение разрабатывается как **монолит** на платформе **ASP.NET Core MVC**

---

## 🔧 Основные возможности

- Управление учетными записями пользователей с ролевым доступом
- Ведение данных по:
  - Организациям
  - Транспортным средствам
  - Сотрудникам
- Работа с типовыми и специфическими документами
- Гибкая система фильтрации, сортировки и поиска

---

## 🏗️ Архитектура

- **ASP.NET Core MVC**
- **Entity Framework Core**
