# FleetManagement System

Веб-приложение для автоматизации управления автопарком с корпоративной системой безопасности и многоуровневой авторизацией.

## 🚀 О проекте

**FleetManagement System** - это монолитное веб-приложение на ASP.NET Core MVC, разработанное как MVP для автоматизации бизнес-процессов управления транспортными средствами. Проект демонстрирует реализацию корпоративной системы безопасности по аналогии с ERP-системами (1С и подобные).

**Статус**: MVP (Minimal Viable Product) - реализована базовая функциональность, работает аутентификация и авторизация, CRUD-операции.

## 🛠 Технологический стек

### Backend
- **ASP.NET Core MVC**
- **Entity Framework Core** (Code First)
- **ASP.NET Core Identity**
- **FluentValidation**

### Базы данных и кэширование
- **MS SQL Server**
- **Redis** (гибридное кэширование)

### Инфраструктура
- **Docker** (контейнеризация)
- **Swagger** (документирование API)
- **Serilog** (структурированное логирование)
- **Mailtrap.io** (тестирование email-уведомлений)

## 🏗 Архитектурные особенности

### Система безопасности и доступа
Реализована многоуровневая система аутентификации и авторизации, имитирующая подходы корпоративных ERP-систем:

- **Регистрация компании** - первый пользователь автоматически становится администратором
- **Ролевая модель** - 4 уровня доступа: администратор, руководитель, диспетчер, контролер
- **Инвайт-регистрация сотрудников**:
  - Администратор добавляет пользователя → отправка email с приглашением
  - Подтверждение почты → установка пароля → доступ к системе
- **Политики доступа**:
  - Администраторы: полный доступ к данным, включая управление персоналом организации
  - Руководители: CRUD транспорта и данных
  - Рядовые пользователи: только чтение

### Бизнес-логика
- **Паттерн Result** - структурированная обработка ошибок с явным моделированием сценариев ("сотрудник уже зарегистрирован", "транспорт не найден")
- **Сервисная архитектура** - бизнес-логика инкапсулирована в сервисах
- **Нормализованная схема БД** - итерационное проектирование с устранением избыточности данных
